All Royco Dawn smart contracts are deployed on public blockchains and can be independently verified by anyone. The tables below list every production contract address across Ethereum and Avalanche. You can verify contract code, inspect storage, and trace historical transactions using any standard blockchain explorer (e.g. [Etherscan](https://etherscan.io) for Ethereum or [Snowtrace](https://snowtrace.io) for Avalanche).

<Note>
  All protocol state is publicly verifiable on any blockchain explorer. Royco Dawn does not require trust in any off-chain data source to audit contract behavior or confirm fund custody.
</Note>
